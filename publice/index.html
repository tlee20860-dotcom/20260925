📖 城戰計算規則（v8.9.6）

一、資料模型

盟（Alliance）：固定總戰力、固定總人數。
城（City）：輸入人數、總戰力、總隊數、等級；平均戰力自動計算。
盟餘下戰力 = 總戰力 − 該盟所有城池總戰力。
地圖路線：兩城之間的「接觸」（無向圖）。

二、戰力單位

輸入單位：億（例：輸入 2 = 2 億）
顯示單位：
・盟 / 城總戰力：億（2 位小數，如 2.00 億）
・平均戰力：萬（無小數，如 150 萬）
儲存：完整數字（億 × 10⁸）

三、對戰節奏

每 30 秒結算一次對撞，每分鐘抽取一次消耗值。
消耗抽取：每條路線獨立，在 [最小, 最大] 之間抽取。

四、隊數分級

城池「總隊數」可由分級人數自動計算。
預設分級：
・≤ 17 級：每人 3 隊
・18~20 級：每人 4 隊
・21~24 級：每人 5 隊
・≥ 25 級：每人 6 隊

五、地圖庫與 AI 節點校準

🗺️ 地圖庫：底圖存 Cloudinary，座標存 Firebase（獨立雲端資料庫）
🤖 AI 全圖辨識：地圖切 3×3，智譜 GLM 辨識城池 + 路線
🎯 定點模式：點左側城池名稱 → 高亮 → 點地圖正確位置 → 記錄座標
🖱️ 拖曳節點：直接拖曳畫布上的節點微調位置
🗑️ 刪除標記：清單中點 🗑️ 可刪除該城池標記
🔍 縮放平移：滾輪 / 捏合 / 拖曳 / 右側按鈕
✅ 自動去重：切片邊界的重複路線自動合併

六、地圖互動模式（v8.9.6）

三模式互斥：
・🛣️ 路線模式（藍框）：點第一城 → 點第二城 → 連線
　再點同對城 → 詢問刪除
・⚔️ 宣戰模式（紅框）：點出兵城 → 點目標城 → 建立宣戰
・🏙️ 城池編輯模式（綠框）：點城池 → 編輯；點空白 → 新增

箭頭顏色：
・🔴 紅色 = 進攻
・🟢 綠色 = 協防

路線樣式：5px 標準寬（縮小時等比變細，放大不變粗）
白色外框 + 黑色虛線主線

七、宣戰清單

  • 進攻：需指定「開始時間」= 目標城防守開始時間。
  • 協防：需與出兵城同一盟、且路線上必須有接觸。
  • 跨戰區限制：預設只能同戰區宣戰。

八、Excel 匯入模式

🔄 合併：同名的更新、新的加入、其他保留。
➕ 新增：同名的跳過、新的加入、其他保留。
💥 覆蓋：清空後重建。

九、協作模式

  • 個人雲端沙盤：登入時下載、定時上傳、保留 20 筆歷史
  • 房間雲端沙盤：房主/幹部手動上載

十、帳號與權限

  • 超級管理員：最高權限
  • 管理員：可停用帳號、修改 extraPerms
  • 幹部：可創建房間、執行推演、編輯地圖庫（需授權）
  • 成員：本機推演、加入房間
  • v8.9.6：地圖庫：所有登入使用者皆可編輯

十一、安全架構

智譜 API Key 儲存於 Cloudflare Pages Functions 環境變數，前端完全接觸不到 Key。
所有 AI 請求經過 /api/ocr 代理。
